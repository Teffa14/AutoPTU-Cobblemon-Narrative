## Source 1 — Collections Trust: renumbering collections

Source: https://collectionstrust.org.uk/resource/re-numbering/
Retrieved: 2026-09-09.

Collections Trust explains that a unique accession number maintains the link between a physical object and its associated information. When that link is broken, the institution can lose accountability even though the object itself still physically exists.

Reusable Ouros structure:

- stable identity is a documentary relation, not a storage coordinate;
- current location may change without changing object identity;
- losing an identifier-to-record link creates a legitimate investigation problem;
- rebuilding that link requires evidence rather than an omniscient lookup.

Pass 390 applies only this high-level documentation structure. It does not import UK museum governance as Ouros law.

## Source 2 — U.S. National Park Service: archaeological project workflow

Source: https://www.nps.gov/articles/000/what-are-the-steps-of-an-archeological-project.htm
Retrieved: 2026-09-09.

The NPS describes archaeological materials being sorted, packaged by provenience, labelled with accession/catalog information, registered in a collections-management system and stored in controlled facilities. Reports preserve project results for later research.

Reusable Ouros structure:

- find context, catalog identity, physical storage and later analysis are connected but separable stages;
- an object can leave its field location while provenience remains historically meaningful;
- later institutional handling should not rewrite the field observation that preceded it.

No NPS procedure is promoted into Ouros canon.

## Source 3 — Collections Trust: object entry and inventory

Sources:
- https://collectionstrust.org.uk/resource/object-entry-scope/
- https://collectionstrust.org.uk/resource/inventory-scope/
Retrieved: 2026-09-09.

Object-entry guidance separates taking responsibility for an object from the later decision about acquisition. Inventory guidance treats unique identity, current location and ownership/source as distinct information fields.

Reusable Ouros structure:

- custody, ownership, identity and location should remain different facts;
- the current custodian may be known even when legal ownership is uncertain;
- an emergency receiving location can preserve an object without resolving its institutional status.

This supports the Pass 390 checkpoint boundary: recovery should preserve the cross-system identity relation while current operational state remains external.

## Narrative synthesis

The combined pattern produces a useful investigation loop:

1. an object is documented at a site;
2. the observation is bound to a stable resource identity;
3. a disruptive event forces evacuation or relocation;
4. custody/location change through external systems;
5. old records continue pointing at the historical place;
6. later actors must reconcile historical identity with current storage rather than treating one record as false.

This pattern supports mysteries where nobody has to lie and no database is omniscient.
