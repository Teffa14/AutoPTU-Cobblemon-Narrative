# Performance, Production, Ensemble, and Reception Research Scan — Pass 159

Status: RESEARCH / PROVENANCE ONLY
Canon effect: NONE
Date: 2026-08-31

## Scope

This pass researches reusable structures for stage performance, artistic production, ensembles, rehearsal, venues, touring, audience reception, recasting, cancellation, documentation, and performance-linked adventures.

It does not establish Ouros canon. It does not import protected characters, dialogue, plots, scoring systems, or setting-specific institutions wholesale.

## Repository gap checked before research

The Narrative repository already contains dedicated continuity for ritual/tradition, public memory, formal education, training/coaching, battle institutions, competitive scouting, festivals inside other social systems, material culture, venues/facilities, travel, organizations, reputation-adjacent public claims, and Minecraft/Cobblemon presentation authority.

The missing connective layer is production continuity itself:

- a work or production can persist across multiple performances;
- a scheduled event can be cancelled, postponed, relocated, or actually performed;
- casts/ensembles can change without retconning earlier versions;
- rehearsal history can exist without granting mechanical progression;
- audience reception can differ by place and date without becoming canonical quality;
- a venue can host the same production more than once;
- a tour can continue after one event fails;
- stage effects can be visual fiction without becoming AutoPTU terrain/weather/hazards;
- a Pokémon can perform on stage without being a combatant.

## Source 1 — Pokémon Musicals, Nimbasa

Source:
https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Musical

Relevant high-level structures:

- a persistent dedicated venue hosts repeated performances;
- props are part of presentation and can be accumulated over time;
- audience response is observable and performance-specific;
- a saved photograph records a particular show with name/date/participants;
- repeated participation can build a social following.

Reusable Ouros lessons:

1. Separate production identity from one performance episode.
2. Preserve concrete performance artifacts such as photographs, programs, props, posters, recordings, costumes, and reviews through Material Culture/Archives.
3. Audience reaction belongs to a dated performance and audience sample. It is not universal truth about artistic quality.
4. A prop can have a production history without automatically having combat Item authority.
5. Venue history can accumulate because productions recur there.

Not imported:

- prop scoring;
- spotlight mechanics;
- follower thresholds;
- game rewards;
- musical categories;
- any numerical audience system.

## Source 2 — Pokémon Contest / Contest Spectacular

Source:
https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Contest

Relevant high-level structures:

- presentation is divided into distinguishable judged phases;
- audience and formal judging can both matter;
- performances use Pokémon Moves as part of presentation;
- combinations and order can affect a contest result;
- a participant can have a public career across many events rather than one isolated appearance.

Reusable Ouros lessons:

1. A performance event may have an authored format with multiple phases.
2. Formal result authority must remain with the governing PTU/Caelo Contest contract when used.
3. Narrative should preserve the event, participants, result source, and public aftermath without recreating Contest arithmetic.
4. Move use in a performance context must not be interpreted as a battle attack unless a BattleSpec actually exists.
5. A contest career can generate rivalries, mentorship, travel, publicity, fatigue, venue history, and creative evolution without every event becoming tactical combat.

## Source 3 — Pokémon Showcase, Kalos

Source:
https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Showcase

Relevant high-level structures:

- events can contain changing theme rounds plus a more stable freestyle component;
- Trainer and Pokémon may perform together;
- audience voting can determine outcomes;
- higher-level events alter format, participant count, and scope of voting;
- performance circuits create recurring competitors and public careers.

Reusable Ouros lessons:

1. Preserve format/version per event rather than assuming one eternal ruleset.
2. Audience participation should be attributed to the actual voting body or observed crowd.
3. A format change is a historical event, not a retcon.
4. Trainer participation on stage is distinct from Trainer combat participation.
5. Regional circuits can create recurring characters without requiring battle-rival semantics.

Not imported:

- gender restrictions;
- Princess Keys;
- Kalos Queen title;
- Glow Caster mechanics;
- specific rounds or characters.

## Source 4 — Wallace Cup / coaching before performance

Source:
https://bulbapedia.bulbagarden.net/wiki/Our_Cup_Runneth_Over

Relevant high-level structure:

A prominent Coordinator observes another performer's practice and gives bounded advice before a major event. The practice can occur through a friendly battle while the artistic objective remains separate from simply winning that battle.

Reusable Ouros lesson:

Training/coaching continuity and performance continuity should link through explicit references. A coach can observe a battle or rehearsal, but their advice does not become mechanical progression or objective artistic truth.

## Source 5 — PTU Coordinator rules reference

Source:
https://pturpg.wikidot.com/coordinator

Relevant mechanical evidence:

- PTU has an explicit Coordinator class;
- features can trigger on Appeal Rolls and Contests;
- some features bridge Contest and battle contexts;
- Contest-specific behavior is mechanically meaningful;
- Innovation references explicit Tutor Point expenditure and created Moves.

Authority lesson:

Narrative must not invent a generic performance roll, Contest score, free Move learning, Tutor Point reward, or Coordinator Feature effect. When an Ouros event is mechanically a PTU Contest, the authoritative Contest/Feature rules must be separately verified and executed by the correct rules layer.

## Source 6 — PTU community Grand Festival discussion

Source:
https://www.reddit.com/r/PokemonTabletop/comments/184p8tq

Community value only:

A GM asking how to run a Grand Festival notes that the regular rules do not directly answer how to make a much larger capstone event feel distinct. The responses are homebrew/community discussion, not rules authority.

Reusable lesson:

A major artistic finale does not need a wholly new mechanical subsystem. Narrative scale can come from recurring rivals, venue prestige, travel, media attention, format stages, old relationships, and accumulated history. Any mechanical expansion must remain explicit rather than silently changing PTU Contest rules.

## Source 7 — PTU community homebrew XY-style Contest discussion

Source:
https://www.reddit.com/r/PokemonTabletop/comments/ck1kb0

Community value only:

The author changed round structure, fashion bonuses, and multi-Pokémon staging to imitate an animated-series format. This is useful evidence of a common design pressure: fiction may suggest a performance structure that the existing tabletop Contest mechanics do not directly model.

Reusable lesson:

Ouros should store event format independently from mechanic authority. If a desired format lacks verified PTU implementation, use a narrative-only performance or a reduced mechanically supported contract rather than quietly homebrewing engine rules.

## Source 8 — UNESCO performing arts and transmission

Sources:
https://ich.unesco.org/en/performing-arts-00054
https://ich.unesco.org/en/transmission-00078

Relevant high-level structures:

- performing practices change while being transmitted;
- knowledge and technique can move through apprenticeship, community institutions, and repeated enactment;
- no two manifestations need to be identical;
- preservation/transmission is not the same as freezing one version forever.

Reusable Ouros lessons:

1. A named performance tradition can have many manifestations.
2. Recasting, adaptation, venue change, instrument change, or revised choreography can be continuity events rather than authenticity failures.
3. Training history belongs in the existing Training/Tradition systems; production history should reference it rather than duplicate it.
4. A performance can carry local identity without its content becoming literal historical truth.

## Source 9 — UNESCO Talchum

Source:
https://ich.unesco.org/en/RL/talchum-mask-dance-drama-in-the-republic-of-korea-01742

Relevant high-level structures:

- dance, music, theatre, dialogue, costumes/masks, ensemble participation, and audience response interact in one performance ecology;
- formal stage infrastructure is not always required;
- audience participation can be part of the event itself;
- performance can express social commentary and local identity.

Reusable Ouros lessons:

1. A venue can be a temporary spatial designation rather than a permanent building.
2. Audience participation may be constitutive of a performance without granting the audience omniscient narrative authority.
3. Performance content can comment on institutions or historical events while remaining authored representation rather than canonical evidence that those claims are true.

## Design synthesis

The strongest reusable model is:

WORK / PRACTICE LINEAGE
→ PRODUCTION VERSION
→ REHEARSAL / PREPARATION
→ SCHEDULED PERFORMANCE
→ ACTUAL PERFORMANCE EPISODE OR CANCELLATION
→ ATTRIBUTED RECEPTION / FORMAL RESULT
→ DOCUMENTATION / MATERIAL AFTERLIFE
→ TOUR / REVISION / RECAST / REVIVAL / RETIREMENT

The model must preserve provenance at every step.

## Required authority separations

- `PERFORMANCE_SCHEDULED != PERFORMANCE_OCCURRED`
- `REHEARSAL_OCCURRED != PERFORMANCE_OCCURRED`
- `AUDIENCE_REACTION != CANONICAL_QUALITY`
- `FORMAL_CONTEST_RESULT != UNIVERSAL_ARTISTIC_QUALITY`
- `PUBLIC_REVIEW != CANONICAL_TRUTH`
- `ROLE_RECAST != PRIOR_PERFORMANCE_RETCONNED`
- `PRODUCTION_REVISED != ORIGINAL_VERSION_ERASED`
- `SHOW_CANCELLED != TROUPE_DISBANDED`
- `POKEMON_ON_STAGE != COMBATANT`
- `MOVE_USED_IN_PERFORMANCE != BATTLE_ATTACK`
- `STAGE_EFFECT != PTU_TERRAIN_OR_WEATHER`
- `PROP_PRESENT != PTU_ITEM_EFFECT`
- `REHEARSAL_COMPLETED != FEATURE_OR_MOVE_LEARNED`
- `APPLAUSE != REPUTATION_TRANSACTION`
- `PERFORMANCE_RECORDING != COMPLETE_OBJECTIVE_RECORD`
- `PERFORMANCE_DEPICTS_EVENT != DEPICTED_EVENT_PROVEN`

## Useful Ouros narrative opportunities

- regional touring troupes whose casts change over years;
- Pokémon-human ensembles with individual participation histories;
- a production revived after a generation with disputed changes;
- a small venue becoming important because an early performance happened there;
- a famous performer returning as director, teacher, critic, sponsor, or audience member;
- conflicting reviews of the same night;
- a cancelled event whose preparations still affected the town;
- a prop with long provenance but no supernatural effect;
- a performance about a disputed historical event that becomes influential despite being inaccurate;
- a tour altered by infrastructure, weather, labor, travel, or political events already modeled elsewhere;
- a noncompetitive festival performance whose success is social rather than score-based;
- a formal PTU Contest whose result is authoritative only through verified Contest mechanics.
