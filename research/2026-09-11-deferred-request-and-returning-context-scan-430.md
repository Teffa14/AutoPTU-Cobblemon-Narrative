# Deferred request and returning-context scan — Pass 430

Status: RESEARCH / NON-CANON
Date: 2026-09-11

## Purpose

Find reusable structures for an assistance response that means “not now; ask me again later” without silently turning DEFER into ACCEPT, a promise, a route reservation or an off-screen action.

## Source 1 — Six Ages development blog: Not Branching

Source: https://blog.sixages.com/index.php/2020/11/05/not-branching/

High-level observation: Six Ages uses context-sensitive scenes instead of a fixed branch tree. A decision can schedule a follow-up much later, after intervening events have changed or invalidated the original context. The article gives the abstract example of a neighboring group returning later after an earlier response; subsequent world state can alter whether the follow-up still makes sense.

Reusable Ouros lesson: a deferred request should preserve a future reconsideration point, not pre-author the answer. When the time arrives, the NPC must evaluate the current world again. The original requester may have solved the problem, the responder may have acquired a harder obligation, the route may have changed, or the request may no longer be relevant.

Excluded: Glorantha setting, clans, named events, dialogue, characters, myths and specific scene text.

## Source 2 — Six Ages / King of Dragon Pass systemic narrative design

Source: https://www.gamedeveloper.com/design/how-i-six-ages-i-builds-a-game-around-the-power-of-myth

High-level observation: the design favors multiple meaningful responses whose results depend on current skills, advice and context rather than a universal correct choice. The broader systemic structure leaves more possible choices than can be taken at one time.

Reusable Ouros lesson: DEFER is useful only if the later wake-up re-enters ordinary agenda competition. It must not carry hidden priority that guarantees assistance. A future replan should still compete with goals, needs, commitments, risk, permissions, travel and newly learned information.

Excluded: myths, named supernatural entities, heroquest content, prose and authored choices.

## Source 3 — public PTU campaign log #9

Source: https://www.reddit.com/r/PokemonTabletop/comments/n8n79k

High-level observation: a prepared encounter changed substantially because players used stealth, grappling, status application, social/creative play and object interaction rather than following the expected combat duration. The GM explicitly noted that the encounter did not consume the expected time.

Reusable Ouros lesson: delayed world-agent decisions should not assume that the tactical problem will still have the same shape later. If a responder reconsiders after a delay, current world evidence must decide whether there is still a battle, a retrieval, a conversation, a repair task or no remaining task at all.

Excluded: player characters, NPC identity, heirloom/orb plot, exact Pokémon composition, dialogue, rewards and encounter sequence.

## Synthesis

A durable deferral needs four facts: who deferred, which request it belongs to, when reconsideration becomes due, and the response action that owns provenance. An optional expiry can prevent a stale “ask again” window from living forever.

The future event should wake only the responder. It should not create assistance by itself. The ordinary planner then evaluates the world that exists at that later semantic minute.
