## Kairos New Player Doc.pdf

Supplied snapshot SHA-256: `f3072829142c72e10aa50474c65e2c2f85ed9817c714245a09b2865a3c9c58a1`

### High-value living-world evidence

- Kairos describes itself as a living-world PTU server in which characters continue interacting, leveling Pokémon, crafting and telling stories outside active quests.
- Many quests are one-shot sessions rather than one continuous traditional campaign.
- The server uses a homebrew Core compilation and additional server rules to adapt PTU to living-world play.
- Real Estate allows persistent property development and upgrades.
- Prestige/post-level-cap play lets a character restart mechanical progression while retaining prior character history/sheets.
- New characters start at Trainer level 1 with a level-5 starter under Kairos-specific creation rules.
- Downtime is a persistent progression loop used for hunting, Pokémon training, Trainer training, crafting, income and fossil activities.
- Pokémon hunting is selected by island/region, biome and requested level range, then generated through a server encounter workflow.
- Kairos supports parallel progression paths including Gym Circuit, Contest Circuit and Guardian Challenges.
- Player-created teams/factions can own public property and pursue their own quests.

### Explicit non-import warning

The New Player Doc states that Kairos uses homebrew content including regional-dex Fakemon, Type Syncs/TOSIKIs and customized Mega/Dynamax/Z-Move content. These are evidence of Kairos's approval process, not content approval for Ouros.

Ouros source ingestion must apply `design/ouros-source-authority-and-species-policy.md` before any Kairos species/form/gimmick data can become a candidate.
