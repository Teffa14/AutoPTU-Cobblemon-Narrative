# Kairos public Drive inventory

Status: SOURCE REGISTRY — NOT OUROS CANON
Indexed: 2026-09-02
Folder: https://drive.google.com/drive/folders/1hj-xdwlW1OXXJzZAh0vpKNX5L_5RKdmT

This inventory records the Kairos source folder supplied by the Ouros project owner. It exists so future research can find the live source instead of repeatedly rediscovering it.

Classification meanings:

- `PREFERRED_CURRENT_REFERENCE`: current/high-value source candidate. Still requires rule-by-rule Ouros review.
- `REFERENCE_ONLY`: useful operational/design evidence; no automatic import.
- `SPECIES_FORM_GATE`: source may contain custom species/forms/mechanics. Never feed directly into Ouros species/form data.
- `ARCHIVE`: older material; use for historical comparison only unless explicitly selected.

## Mandatory Ouros gate

Nothing in this inventory becomes canonical or mechanically active by being listed here.

In particular:

- Kairos regional Pokédexes, MegaDexes, Type-Shift/TOSIKI/Burst/Mega templates, mystery Pokémon data and Approved Pokémon must never flow directly into Ouros species/form data.
- Fakemon and unofficial forms require exceptional explicit Ouros authorization.
- Fusion content is prohibited by default and cannot be admitted by an ordinary source/content approval.
- Official species/forms still require Ouros regional/content enablement and mechanical-profile validation.
- Old Stuff is archival evidence, not default authority.
