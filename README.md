# AutoPTU-Cobblemon-Narrative

Narrative and world-state design repository for the Ouros AutoPTU + Cobblemon project.

The long-term goal is a persistent Pokémon world where player decisions, battles, discoveries, relationships, faction activity and environmental changes can become durable world state. Minecraft/Cobblemon provides the explorable overworld; AutoPTU provides the tactical grid-battle rules engine.

## Repository layers

### `research/`

External-source research and provenance. Nothing in this directory is automatically Ouros canon.

Research may study publicly accessible PTU campaigns, actual plays, Pokémon roleplay, fangames, manga/spinoff structures, fanfiction communities and general narrative/game-design work. It should extract high-level structures and design lessons without copying protected prose, dialogue, distinctive characters or complete plots.

### `design/`

Narrative architecture, schemas and implementation-facing design documents.

### `proposals/`

Original Ouros worldbuilding, quest, faction, NPC, dungeon, encounter and story-arc candidates. Material here is explicitly non-canon until reviewed.

### Future `canon/`

Only reviewed material should be promoted to canon. Canon promotion should include provenance/originality review, continuity review, PTU/Caelo rules review where mechanics are involved, and feasibility review for AutoPTU + Minecraft/Cobblemon.

## Mechanical source priority

Narrative proposals must not invent combat legality.

When mechanics are required, validate against the project's supplied PTU/Caelo source set, including the PTU Core Rulebook, Pokédex material, Caelo Player's Guide, Caelo rulebook/errata, character-creation material and Caelo Region Location & Encounter List, plus the actual AutoPTU implementation state.

External stories are inspiration sources, not rules sources.
