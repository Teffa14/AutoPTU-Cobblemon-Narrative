# Marea / Sendero facilitation cascade loop

Status: PROPOSED. Pass 268. All structures, dependency relations and behaviors in this proposal are non-canon unless separately approved.

The player first notices a small persistent microhabitat feature being used repeatedly. A later visit reveals that the visible feature itself depends on an older physical modification. A third observation exposes another organism or structure using the secondary feature. The investigation grows by reconstructing a dependency chain rather than by revealing a single hidden quest answer.

The key dramatic rule is that each link can be wrong independently. Repeated co-occurrence can suggest an edge, direct observations can strengthen it, and later evidence can reject it. Discovering A -> B and B -> C never grants A -> C automatically. This lets NPC testimony, field notes and player interpretation disagree without corrupting ecological truth.

A useful world-event beat occurs when the oldest feature degrades. Downstream features are then re-evaluated one by one. Some may disappear, some may persist autonomously, and some may remain physically present while their ecological interpretation becomes uncertain. Returning after this change produces environmental storytelling without requiring a battle or scripted NPC exposition.

Reduced implementation: persistent modification nodes, evidence-backed directed edges, observations, semantic horizons, restart-safe storage and Minecraft/Cobblemon presentation. Already-counted population sources can visit features. No PTU terrain meaning, combat state or autonomous tactical behavior is required.

Full implementation: actors can discover, construct, contest, damage or exploit cascade features during play. That path requires the exact engine capability families identified in the Pass 268 contract. A reduced version remains valid while tactical terrain and AI policy are incomplete.

Longer-term arc candidate: multiple investigations can reveal that a visually minor feature is structurally important because it enables another modification that is the actual local biodiversity hotspot. Removing the first feature before understanding the chain can alter what is observed later. This consequence should be driven by approved world-state transitions rather than a moralized correct/incorrect quest choice.

Canon questions remain open: which Ouros species can author modifications; whether any Marea/Sendero site supports a multi-level cascade; what direct evidence qualifies an edge for canon review; and which modifications remain self-supporting after their upstream dependency disappears.
