# Ouros library circulation, borrowing & interlibrary loan seeds — Pass 171

Status: NON-CANON CANDIDATES
Date: 2026-08-31

These concepts depend on the proposed library-circulation continuity layer and require canon review before adoption.

## The Book That Was Returned but Never Checked In

A patron deposited a field guide before leaving town. The return room closed during a storm, so the system still shows the copy as checked out. The guide is physically present, the patron is technically overdue, and nobody involved is lying.

Use: procedural mystery with no villain required.

## Five Times Someone Said “The Library Lost It”

A popular local history passes through five states that all sound like “lost” in ordinary speech: on the wrong shelf, checked out under an old account, in transit between branches, awaiting conservation, and genuinely missing.

Use: teach players to distinguish operational labels from physical truth.

## The Remote Box

A mountain settlement receives a rotating crate of books every few weeks. The crate becomes part of the settlement's rhythm: children wait for stories, a mechanic waits for manuals, a ranger returns maps, and elders request local-history copies. One delayed route therefore affects several unrelated lives without becoming a disaster plot.

## The Hold Queue for the Wrong Edition

Everyone wants the newest regional field guide because it is famous. An older edition with almost no demand contains a now-obsolete trail description that matches a structure the party recently found.

Use: reward catalog comparison rather than rarity hunting.

## Two Libraries, One Copy

Two institutions both have records saying the same manuscript is currently theirs. The physical copy exists in only one place. The explanation may be an old institutional transfer, a duplicated accession number, a copy mistaken for an original, or a catalog migration error.

No theft should be assumed without evidence.

## The Borrower Who Never Read It

A researcher checked out a controversial book for months. Rumor later treats that as proof they believed its claims. Their actual notes show they borrowed it only to verify citations made by someone else.

Use: separate possession, reading, belief and endorsement.

## The Mobile Library Became the Archive

For decades, a mobile library route collected duplicate newsletters, school pamphlets, club programmes and small local histories while distributing books. Long after the service changes, its storage room unintentionally contains one of the best documentary records of several tiny settlements.

## The Last Circulating Copy

A practical manual remains heavily used because the reference copy cannot leave the library. The circulating copy has repairs from several generations of borrowers. Replacing it would improve service but remove a material object with its own community history.

Use: connect circulation with Material Culture without making old equal magical.

## The Return Chute Note

A returned book contains a folded note clearly written for a prior borrower. Library staff must decide whether it belongs with the book, should be treated as lost personal property, or contains something that requires another institutional process. The note is not automatically evidence or public information.

## The Branch Closure Reconciliation

A small branch closes temporarily for building work. Its active holds, checked-out copies, returns and patron pickup locations must move to nearby branches. Some records say an item is “at” the old branch because its home location differs from its present physical location.

## The Interlibrary Loan That Arrived First

A requested technical volume reaches a rural branch before the message saying it was approved. The book is physically there, but the patron has not yet been told and the circulation desk cannot assume the notification succeeded.

## The Book Recovered Years Later

A copy declared lost and replaced turns up inside a sealed storage box after a building renovation. The replacement remains a legitimate library object. Recovery reopens provenance and stewardship questions but does not erase the loss declaration or the replacement history.

## The Reading Room Regular

An elderly patron reads the same newspapers and regional bulletins every week but never checks anything out. A circulation-only model would falsely make this person invisible. The library should support observed use without forcing a permanent reading-history dossier.

## Long arc: The Library Across Forty Years

Follow one civic library through repeated campaigns. Shelves change, branches open or close, catalog conventions change, some materials become reference-only, mobile routes expand and contract, and former child patrons later become staff or donors. The institution persists even as almost every operational detail changes.

## Long arc: The Book Everyone Remembers Differently

A widely borrowed local-history volume influences several generations. Later corrections reveal that one chapter overstated an event. Chronicle preserves the real event, Public Memory preserves the book's influence, Archives preserves editions and corrections, and circulation records preserve only whatever borrowing history policy actually retained.

## Long arc: The Network Makes the Region Smaller

Independent local libraries gradually create a cooperative borrowing network. The major story is not centralization but access: isolated communities can request material from elsewhere while retaining local collections and identities. Disruptions to routes create believable travel hooks without requiring every settlement to own every book.

## Encounter candidates

Mobile Library Route Interruption: protect access to a delayed rural service without putting the vehicle or books into tactical state in the reduced implementation.

Interlibrary Transfer Chokepoint: clear a route used by a temporary loan shipment; battle victory establishes only immediate route safety.

Flooded Return Room Access: regain safe access after a facility incident; condition assessment and check-in happen outside AutoPTU.

Reading Room Evacuation: remove civilians before tactical resolution in the reduced version; the combat transcript cannot decide collection custody, patron knowledge or institutional policy.

## Canon questions raised

Potential review questions for Ouros:
- which settlements actually maintain public libraries;
- whether some institutions share a regional borrowing network;
- whether mobile-library services exist;
- which material classes circulate and which remain reference-only;
- whether accounts depend on residence, school, employment, sponsorship or another authored basis;
- how much borrowing history institutions retain;
- whether overdue material produces only service restrictions or also financial consequences;
- how interlibrary transport integrates with existing courier infrastructure;
- how reading access is represented for player-facing lore without turning every book into a UI wall.
