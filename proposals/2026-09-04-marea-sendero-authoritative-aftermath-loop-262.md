# Marea / Sendero authoritative-aftermath loop — Pass 262

Status: PROPOSED NARRATIVE / SYSTEM CONTENT. No new canon actor, Injury, status, NPC, faction or quest is established here.

## Premise

A wild Pokémon that has already accumulated meaningful history may later take part in an AutoPTU encounter. When the player returns to the same area, Ouros should be able to present consequences of that encounter only when those consequences came back through an authoritative semantic result bound to the same ecological source.

The narrative value is continuity. The world can remember what genuinely happened without turning every animation into lore.

## Reduced version

Use a fixture-prevalidated semantic envelope already accepted by the ingress contract. The scene begins after adjudication.

On a later visit, the player can encounter evidence consistent with the accepted consequence. The public-facing description stays bounded by what the character can observe. Internal result IDs, battle-session IDs, actor bindings and quarantine state remain hidden.

A Minecraft-only hit animation, generic damage flash or despawn produces observation evidence at most. It cannot make the later scene claim an Injury or persistent status.

This version requires ecological persistence plus Minecraft/Cobblemon/Craftics adapter/playback support. It does not require live tactical AutoPTU execution.

## Full version

A real encounter begins from an Ouros-bound subject, hands that stable subject binding into AutoPTU, resolves through the authoritative battle runtime, emits a typed result envelope and imports it back into Ouros.

A later field scene can then react to the accepted result. Possible original Ouros patterns include:

- a recurring individual changes where it rests while an accepted persistent consequence remains active;
- an observer notices a previously documented individual behaving differently and must distinguish actual aftermath from ordinary variation;
- a local field record contains a gap because the individual is less visible after the encounter, without declaring death or emigration;
- recovery becomes a longitudinal observation problem after the owning PTU consequence has genuinely closed.

These are structures, not canon events for the current Fletchling population.

## Failure paths as narrative protection

If the subject binding does not reconcile, Ouros keeps the result quarantined and does not attach it to whichever similar Pokémon happens to appear.

If the result type depends on an engine capability path that is not currently admitted, the world delays the persistent interpretation. Presentation can still show the battle playback, but the narrative database does not manufacture a durable consequence.

If the same result is delivered twice, the second delivery changes nothing. The player never sees an Injury multiply because a transport retried.
