# Return to the Scene — memory-assisted investigation loop

Status: PROPOSED / NON-CANON
Pass: 294

A recurring NPC witnessed or learned something important long before the player becomes involved. Their persistent ledger still contains the event, but present unaided recall is weak. The investigation can progress by finding a context that was genuinely tied to the original information.

A reduced version works entirely at world-simulation level. The player interviews the witness, gets only partial content, returns with them to a relevant place or object, presents a valid cue, and receives a stronger but still provenance-bounded recollection. An archive can independently corroborate or contradict the memory. The documentary result does not automatically become the witness's own memory.

A mechanically richer version can place the original scene inside a dangerous route, abandoned facility, ecological disturbance, contested arena, collapsed structure or active faction site. The narrative premise remains the same if the battle layer is reduced: the clue is tied to revisiting context, not to winning a particular fight.

Possible consequence patterns include a witness recovering the location but not the source; recovering who issued an order while still misremembering timing; an archive proving that a report existed even though every living witness currently fails to recall it; two characters receiving different effective cues and therefore exposing different fragments of the same older event; or a rival deliberately leading investigators to an irrelevant context that produces no valid retrieval bonus.

Capability dependencies for the reduced form: none of the AutoPTU battle categories are required.

If an authored full form contains structured combat, declare only the families actually used. Ordinary ranged or area positioning requires targeting/footprints/range/LoS. Traversal legality requires base movement legality. Push, pull, knockback, interception or forced movement require complete movement. Mechanical hazards, weather, zones or reactions require terrain/weather/hazards/zones/reactions. Delayed or phase effects require full turn/round lifecycle plus the owning move/status/ability/item/Feature family. Autonomous tactical decisions require AI tactical policy. Visible execution in-world requires Minecraft/Cobblemon/Craftics adapter/playback support.

Canon questions remain open: which local objects and locations qualify as reliable cues; whether especially salient events receive authored cue bindings; who owns archives; what permissions gate records; and whether deliberate deception can create a false remembered source without corrupting the real provenance ledger.
