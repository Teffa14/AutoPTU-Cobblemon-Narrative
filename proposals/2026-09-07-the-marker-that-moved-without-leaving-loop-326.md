# The Marker That Moved Without Leaving — Pass 326

Status: PROPOSED / NON-CANON
Date: 2026-09-07

## Premise

A route-maintenance crew begins work from an old control marker that appears exactly where the archived field description says it should be. A second team later measures the same corridor from two surviving reference points and concludes that the control location is no longer reliable.

The argument escalates because both teams have evidence.

The mystery is not “who moved the marker?” by default. The real question is which spatial claim remains trustworthy enough for present decisions, and why apparently compatible evidence diverged.

## Persistent site structure

Candidate features:
- `survey_ridge_primary_mark` — historic control point or monument;
- `survey_ridge_reference_a` — surviving secondary reference;
- `survey_ridge_reference_b` — second independent reference;
- `old_fence_or_wall_alignment` — visible historical line that may have shifted, been rebuilt or merely been interpreted differently;
- `maintenance_cut` — present work zone whose placement depends on the control decision;
- `archive_viewpoint` — landscape feature named in older descriptions;
- `route_fork` — downstream consequence if one alignment is accepted.

All names are placeholders until canon review.

## Opening state

The player receives two reports.

Report A says the primary mark was recovered, its stamping/description match, and maintenance may proceed.

Report B says two reference relationships do not converge on the mark's present location closely enough for the team to rely on it.

Neither report is automatically false.

## Investigation loop

The player can:
- recover the primary and reference features;
- compare identifiers and surrounding description clues;
- inspect whether the visible setting looks disturbed;
- obtain earlier recovery reports or field notes;
- compare an older map with current feature geometry;
- ask the two crews exactly what they observed rather than accepting their summaries as equivalent;
- locate a replaced landmark that older descriptions still mention;
- return after an institutional review to see what changed.

The central deduction should be scoped:

`THIS_EVIDENCE_SUPPORTS_THIS_SPATIAL_CLAIM_FOR_THIS_DECISION`

It should never collapse into omniscient “the map is wrong” or “the marker is right.”

## Candidate explanations

Several explanations remain available until authored canon chooses one:
- slow soil movement displaced the physical monument;
- erosion altered its setting;
- maintenance previously reset a visible monument without preserving the original control relationship;
- the primary was correctly identified but no longer stable;
- one reference point was rebuilt or moved while another survived;
- an old field description uses a landmark that changed identity over time;
- the crews used different historical revisions of the same control record;
- the corridor itself was rebuilt while the geodetic control stayed correct;
- several small changes accumulated and no single actor caused the discrepancy.

Sabotage is possible only if future canon supplies evidence. It is not the default answer.

## NPC and institution dynamics

Candidate roles:
- field surveyor or mapping technician;
- route-maintenance supervisor;
- archive/records staff member;
- property or land-use administrator with a narrowly authored mandate;
- local resident who remembers a rebuilt feature but has no automatic technical authority;
- contractor whose work schedule depends on a decision;
- researcher interested in long-term landscape movement.

Each actor has a different evidence subset.

The field technician may know current measurements but not old work orders.
The archive worker may know document lineage but not physical condition.
The supervisor may know operational deadlines but only receive a summary of the survey.
A resident may know that a wall moved twenty years ago but not why.

Shared institution membership never transfers these facts automatically.

## Decision outcomes

Possible decisions should be feature-scoped:
- pause only the maintenance cut whose alignment depends on the disputed control;
- keep the main route open while closing a work spur;
- authorize a temporary alignment with explicit review date;
- require a new control observation before permanent work;
- accept one control chain for route maintenance but leave a separate boundary question unresolved;
- publish a corrected field notice without deleting the earlier version.

A later revision should preserve which decision was made from which evidence.

## Persistent consequences

On revisits, the player may find:
- a replacement or re-established mark with lineage to the earlier control;
- a changed route edge;
- a delayed construction schedule;
- a corrected map or notice received by some NPCs but not others;
- disagreement reduced in one institution but still present in local memory;
- a new monitoring obligation;
- an archive note linking the new reference to the old one;
- ecological or access consequences if the final alignment changes where people travel.
