# The Choice Survived Restart — Pass 441

Status: PROPOSED / NON-CANON
Canon effect: NONE
Location assignment: UNRESOLVED

Premise

A local specialist has already accepted a narrow inspection appointment. Before the start, credible evidence says the normal access route is closed. At the accepted start minute the closure is still active. The specialist decides to wait for clearance rather than improvise around the restriction.

A server restart occurs after that decision.

The narrative requirement is simple: restore the whole causal chain. The agreement still existed. The route was still blocked at start. The specialist chose to wait. None of those facts can disappear merely because another component checkpoint was newer or older.

Reduced implementation

This version uses only world-level systems:

- negotiated assistance commitment;
- pre-start viability evidence;
- semantic-time start watch;
- `BLOCKED_AT_START` assessment;
- responder disposition `WAIT_FOR_CLEARANCE`;
- checkpoint V5;
- later communication or new evidence through existing owners.

Possible later outcomes include clearance arriving, the appointment window expiring, the requester learning about the delay, a new offer being proposed, or another actor solving the original problem. None requires battle resolution.

Full encounter version

If access later reopens into a dangerous field condition, the same premise can become a survey, escorted inspection, retrieval, protection or extraction scene. The objective remains the promised work rather than automatic defeat-all combat.

Narrative consequence hooks

If the closure clears during the window, the specialist can reconsider without erasing that they initially waited.

If the window closes first, a later missed-obligation/accountability owner can distinguish documented impossibility from unexplained absence without deciding blame automatically.

If another route appears, travel authority decides whether it is known, permitted and feasible. The disposition record itself never grants a bypass.

If the requester never received the closure information, they may reasonably interpret the absence differently until communication occurs. This preserves private knowledge and supports later misunderstanding, explanation or trust repair without omniscient relationship updates.
