# The Kit That Returned Before the Team — Pass 395

Status: PROPOSED / NON-CANON.
Date: 2026-09-10

## Premise

A field team is still away from base with a shared technical kit. A desk record indicates that the reservation window ended and another task expects the kit to be available. A separate custody record still points toward the field team. A later catalog generation may show the object at base, in transit, or still held depending on which real transition occurred.

The mystery begins when people act on different legitimate records rather than when the server invents one omniscient answer.

## Core dramatic question

Did the kit actually return, did only one administrative obligation close, did another authorized transfer occur, or is one restored record explicitly incompatible with the others?

The scenario should allow several mundane explanations before introducing sabotage or deception.

## Actors

These are archetypes only. Names, institution and location remain unset.

Field specialist: currently using or believed to be using the kit.

Dispatcher: assigns work from reservation and availability information.

Depot keeper: sees physical returns and current storage state.

Second team lead: has a legitimate later need for the same capability.

Local witness or remote correspondent: can provide evidence about when the first team left or whether the object was physically present.

## Reduced version

The reduced version requires no AutoPTU session.

The player receives a second assignment that appears ready because one institutional record says the needed kit should be back. At the depot, current state and historical records do not line up cleanly. The player can contact the first team, inspect available records, verify the present catalog state, locate a substitute resource, delay the task, or reroute to collect the kit if permission exists.

Pass 395 ensures explicit restored-state contradictions fail before the world activates. Incomplete history remains available as an in-world investigative problem.

Success can mean proving the actual current location, obtaining an authorized substitute, correcting the schedule, or safely postponing the dependent job.

## Rich version

The first team is delayed in an exposed area and still has the kit. The player can combine retrieval with assistance or evacuation.

Possible scene objectives include locating the team, keeping the carrier mobile, protecting the equipment long enough to withdraw, transferring custody at an agreed point, or abandoning the resource to prioritize rescue.

Defeating all Pokémon is never the required narrative victory condition unless a later authored encounter explicitly makes it so.
