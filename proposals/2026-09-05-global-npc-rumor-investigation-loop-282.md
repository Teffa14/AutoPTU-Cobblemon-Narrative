# Global NPC rumor / investigation loop — Pass 282

Status: PROPOSED WORLD-AI CONTENT PATTERN
Canon: NOT APPROVED BY THIS FILE

A recurring Ouros mystery should be able to exist because different people know different things, not because every NPC waits to deliver one authored clue in sequence.

A reduced loop can begin with a world event that several agents experience differently. One NPC sees a route gate close. Another hears the report later. A third repeats that report. A fourth independently sees the same condition. The player can speak to them in any order. The apparent number of witnesses can therefore differ from the number of independent evidence roots.

The world-agent layer preserves who observed what, who transmitted it, when the message moved and how much support each receiver currently assigns. A faction does not instantly synchronize the report. An absent NPC can remain unaware until a communication channel reaches them.

This supports original quest structures such as a missing traveler, disputed sighting, changing environmental condition, suspicious delivery, tournament rumor, faction allegation or rival's claimed achievement. The same architecture works globally without a region-specific mystery engine.

The interesting consequence is social and practical. An NPC who believes a bridge is unavailable may leave early by another route. Another may wait for confirmation. A trusted friend's warning can be actionable while still being recognized as hearsay. Independent evidence can strengthen a position. Contradiction can reopen the investigation instead of deleting the old version of events.

Full intended version can later include witness interviews, deliberate deception, source confusion, documents, surveillance, field observation and belief-aware dialogue. Those capabilities are not declared implemented by Pass 282.

The reduced implemented version needs no AutoPTU capability. It uses persistent NPC ledgers, semantic time, explicit communication and deterministic belief assessment.

If the mystery escalates into a structured chase, confrontation or battle, Ouros must request AutoPTU. The encounter then declares only the exact capability families it uses. Knockback or interception depends on complete movement; mechanical weather/reactions depend on terrain/weather/hazards/zones/reactions; multi-turn consequences depend on lifecycle; autonomous battle decisions remain blocked by AI tactical policy until that family is verified. Memory or belief never supplies those mechanics.

Minecraft/Cobblemon can eventually render conversations, gestures, travel and local observations. It cannot create an observation simply because two entities were loaded near each other unless the world adapter emits the corresponding accepted semantic event.

Open canon questions remain who has access to which institutional records, what communication technologies exist by place and era, which NPCs are persistent enough for individual ledgers, and how deliberate deception should affect relationships when discovered. None is answered by synthetic fixture data.
