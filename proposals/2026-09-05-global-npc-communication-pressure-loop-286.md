# Proposal — Communication Pressure and Delayed Knowledge Loop

Status: PROPOSED, NOT CANON
Date: 2026-09-05

## Premise

Ouros can create world events where the important question is not only what happened, but how quickly different people learned about it and what they did before the information reached them.

A route closure, tournament result, missing traveler, environmental hazard, faction movement or unusual Pokémon sighting can originate as one private observation. The witness chooses a small explicit audience. Each selected recipient receives an envelope through a real channel with semantic latency. Busy periods can defer due deliveries without deleting them.

## Reduced version

This version requires no structured battle mechanics.

Example structure:
1. an NPC observes a world fact;
2. relationship/duty state selects two recipients;
3. one message arrives quickly and one waits behind other due work;
4. the first recipient replans travel or work;
5. the second continues acting on old information until delivery;
6. the player encounters different consequences because those agents learned at different times.

The narrative premise survives entirely in Ouros world-state systems.

## Full version

A delayed warning can later create a structured encounter. For example, an escort proceeds into a dangerous segment before the closure warning arrives. When the encounter starts, Ouros hands control to AutoPTU.

The encounter must declare only the capabilities actually used. If the full scene uses interception, forced movement or knockback, it depends on complete movement. Mechanical weather, hazards, zones or reactions depend on that capability family. Temporary/delayed effects depend on lifecycle/status plus their owning Move/Ability/Item/Feature behavior. Autonomous tactical choices depend on AI tactical policy. Visible end-to-end playback depends on Minecraft/Cobblemon/Craftics adapter support.

A reduced version can replace an unsupported tactical encounter with a semantic delay, missed appointment, blocked route or non-combat rescue request while keeping the information-pressure premise intact.

## Reusable quest hooks

- A courier knew a bridge was closed, but the warning to another traveler remained queued during an emergency surge.
- A duty officer receives an institutional report before a close friend because the sender chooses both recipients through different channels.
- Several faction members remain unaware of a danger because shared membership did not create a broadcast.
- A player learns that an apparent cover-up was actually a communication backlog, while another case truly involved selective withholding.
- A public bulletin board later surfaces a persistent request that private recipients could not handle, using a future publication system rather than synthetic private fanout.

## Consequences

This system can create lateness, missed meetings, stale plans, conflicting witness timelines, uneven preparedness and believable regional information gradients without scripting separate branches for every NPC.

## Canon boundary

No specific communication technology, institution, newspaper, radio service, bulletin board, region or NPC is canonized here. The proposal describes reusable world-agent behavior only.
