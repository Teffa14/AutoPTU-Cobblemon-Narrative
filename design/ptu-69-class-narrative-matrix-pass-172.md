## Coverage policy

This matrix is intentionally conservative. A class is `READY_FOR_ARC_DRAFT` only when existing Ouros layers already provide enough varied narrative material to draft a long-form arc without inventing unsupported class mechanics.

`NEEDS_RESEARCH` does not mean the class lacks narrative potential. It means the next pass should seek source structures specifically useful to that fantasy before canon-quality questline drafting.

## Multiclass intersection rule

When a character has several classes, episodes may expose multiple valid approaches to the same canonical situation. The system should record which approach was actually used but must not create four copies of the event.

Example:

A Chef/Researcher/Survivalist/Commander entering a food-supply crisis could access culinary, scientific, field-logistics and coordination hooks. The player can combine them where world state allows. Completion is attached to the shared crisis and relevant class-thread histories, not to four mutually inconsistent alternate universes.

## Respec rule

If the character later removes one of those classes:

- completed events remain completed;
- NPC relationships remain;
- discovered facts remain known according to provenance;
- faction state remains;
- current mechanical actions are revalidated against the new build;
- future quest eligibility is recalculated.

No completed narrative history is deleted simply because a class leaves the build.
